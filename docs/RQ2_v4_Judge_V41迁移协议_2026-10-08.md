## 命令

先只读检查（不加载模型、不调用API）：

```bash
rq2_v41_config=configs/stage2_rq2_qwen7b_advbench_replication_dev_v4_judge_v41_run01.json
python experiments/rq2_replication_rejudge.py --config "$rq2_v41_config" validate
```

确认平台请求名和费用后，只运行新Judge与CPU事件分析。首次运行自动导入已生成回复；程序自动读取项目`.env`：

```bash
python experiments/rq2_replication_rejudge.py --config "$rq2_v41_config" run \
  --from trajectory_behavior_judge --through state_index \
  --acknowledge-cost --confirm-no-external-rq2-use
```

查看完成状态：

```bash
python experiments/rq2_replication_rejudge.py --config "$rq2_v41_config" status
```

检查新的事件人口与评分一致性后，才可以单独运行Oracle（本次代码修改不授权/启动此步骤）：

```bash
python experiments/rq2_replication_rejudge.py --config "$rq2_v41_config" run \
  --from layer_map --through report \
  --acknowledge-cost --confirm-no-external-rq2-use
```

不再用旧 v4 命令续跑Judge，也不要用仅适用于v3的 `rq2_judge_revision.py`。后续新增RQ2实验必须显式绑定新Judge配置；已有历史配置不做原位批量替换。
