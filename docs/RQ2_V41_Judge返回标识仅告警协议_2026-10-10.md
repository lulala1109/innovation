# RQ2 V4.1 Judge 返回标识仅告警协议

用户于2026-10-10授权将当前dev实验的模型身份策略从“两个未确认别名白名单”改为“固定请求入口，返回标识仅记录与告警”。这不是确认多个名称具有相同权重、部署或推理实现。

## 固定范围

请求模型仍为 `DeepSeek-V4.1-Flash`；API地址、评分模板、参数、样本、事件、候选层、效应门槛、统计方法均保持原协议。请求名和地址受来源配置与代码哈希约束。

仅当前独立20条dev的Oracle评分、分析和报告启用本策略。既有v1/v2/v3/v4、alias01的源码/配置/输出不改。新输出目录为 `outputs/stage2_rq2/independent_replication/qwen7b_advbench_replication_dev_v4_run01_judge_v41_warn01`。

禁止GPU、基线重评分、mechanism、subspace、protocol_lock及formal。即使数值门槛通过也不自动转入其他实验。

## 名称与其他门禁分离

响应中的model名称变化、新名称、缺失或无效，仅记录警告，不因此中断。每份原始回执保持原样；逐次账本保留实际返回信息，`scoring/model_identity_audit.json`记录名称计数、切换和未知记录。计数单位是HTTP回执，包含重试，不能视作独立pair或用于无控制的模型效果比较。

用量缺失/不一致、输入或输出超出预留、金额或请求次数达到上限、响应格式无法通过有限修正、HTTP结果不明、缓存/内容/回执冲突，仍按原规则停止。HTTP不自动重试，唯一输入最多3次总尝试、格式修正最多1次；累计30元和7080次HTTP上限不重置。

返回标识不进入用于反复重评的选择规则。按“相同指令内容＋相同回复内容＋本服务评分协议”复用首个有效付费结果；不为同一内容挑选更有利的模型名称或评分。不声称同一服务跨请求完全确定。

## 来源审计与离线恢复

冻结alias01完整来源清单的哈希；锁定全部祖先run，禁止同时写入。逐条检查1915次账本的请求哈希、预留、实际用量和费用、回执原始model、缓存和已有标签。非名称异常不能被本协议豁免。

第1915次回执因第三个标识而未进入缓存；只有原始请求身份、用量和评分格式全部核验通过才离线恢复。前1914次付费记录及已有标签全部保留；标签只改变新协议指纹，不改变分数。历史来源key、原始回执、生成trial_id及原生成指纹保留。

原始5次请求0.010578元继续计入，alias01累计1915次的记账费用为4.307948元，合计1920次HTTP、4.318526元。此为原高峰单价的保守记账，不是平台实际账单。剩余成本由冻结配置的离线审计按未评分唯一输入数和历史均值估算；不新增GPU计算，实例等待租金另计。

报告必须同时写明固定请求模型、服务版本未锁定、名称未验证等价、所观察的返回标识及计数。结果仅为当前dev服务级证据，不作为固定Judge版本的正式因果证据。

## 操作

项目根目录执行。入口自动读取项目 `.env`，不修改终端已有环境变量。

```bash
rq2_warn_config=configs/stage2_rq2_qwen7b_advbench_v41_dev_warn01.json

# 离线恢复，不调用API或GPU，可重复校验
python experiments/rq2_dev_judge_resume.py --config "$rq2_warn_config" prepare

# 仅继续Oracle评分、分析、报告；执行前显示费用估算
python experiments/rq2_dev_judge_resume.py --config "$rq2_warn_config" run \
  --from oracle_judge --through report \
  --acknowledge-cost --accept-unlocked-judge
```

`validate`、`status`、`estimate` 均不调用API。不要继续使用旧alias入口或删除旧fatal_error。此次实现与prepare不等于授权自动执行新的收费请求。
