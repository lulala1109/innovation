独立目录：`outputs/stage2_rq2/exploratory/qwen7b_advbench_post_oracle_explore_v1_run01/`。仅复用当前 20 条 dev，不加入旧 dev、reserve 或 40 条 causal-test。不按分数、干预效果或事件持续性换样本。

待探索问题：在指定 full-state 恢复未达到稳定性门槛时，限定音频 token、prefill 一次的 R 分量恢复是否产生行为变化；这些变化与等幅 H/随机方向相比如何；在 clean 上减去 R 后有无相反变化；同 pair 事件窗口中效应如何变化。Full-state 不是 R 干预效果的数学上界，未通过 Oracle 不等于已经否定 R。

## 固定计划

保留冻结模型、RQ1 probe/方向、生成参数（最多 100 新 token、贪心生成）、clean 参考与首次不拒答事件。PGD 不重跑，不重选 t*，零效用事件保留。第 27 层仍不执行。

| 子实验 | 层与条件 | 新增回复上限 |
|---|---|---:|
| 事件中心恢复 | 19/24/26：R=1.0、R=0.5、H=1.0、sham、随机方向 3 次；18/20/23/25：R=1.0 | 500 |
| clean 反向抑制 | 19/24/26：R 抑制=1.0、R 抑制=0.5、H 抑制对照、sham、随机抑制 3 次；匹配对照剂量均为 1.0 | 420 |
| 事件窗口 | offsets=-2/-1/+1/+3；19/24/26 各做 R=1.0、H=1.0、sham、随机方向 3 次；offset=0 复用本轮机制中心 | 1,440 |
| 总计 | 20 条 dev 全部有完整窗口时 | 2,360 |

1.0 是主剂量；0.5 只作敏感性描述，不单独作对照优越性的确认。R 恢复将所选 token 的平均 R 投影推向同 pair clean 投影，不保证单调增加 R；实际投影变化由原算子审计记录。H/random 使用对应 R 的单 token 位移范数；clean 反向抑制沿用冻结 RQ1 refusal sigma 的剂量定义，不是恢复操作的严格逆映射。

所有作用位置仍为全部 audio token、prefill 应用一次，不改变读出位置或 decode 策略。本轮不声称已经排除 token 位置特异性，不另加未经可达性核验的位置对照。

窗口预先固定为同一 t* 的 [-2,-1,0,+1,+3]。五个位置都可用才进入窗口共同人口；至少 16 条，否则在 GPU 前停止并报告缺失，不替换或改变 offsets。中心机制仍使用完整 20 条，不因窗口缺失排除中心样本。窗口比較仅在完整窗口共同人口中进行。

无干预基线从旧轨迹逐 trial_id 映射导入，机制需 20 条事件中心加 20 条 clean，窗口最多另 80 条。无需新生成这 120 条基线。新生成的 sham 必须与旧基线逐字 SHA 一致；不一致时先停止，不花费 Judge 费用来掩盖生成漂移。

沿用累计 30 元人民币暂停线和累计 7,080 次 HTTP 上限，不重置旧账本消耗。高峰输入 2 元/百万 token、输出 9 元/百万 token 是用户此前提供价格的记账依据，不是本次在线查询或实际发票。

GPU 生成逐 pair 执行并清理 prompt/参考激活缓存，避免窗口检查点累积占用显存；不改变 pair 内计划、随机种子或配对基线。

## 分析与结论

三终点分开：恢复 ΔU=S_base−S_patch；ΔR=R_patch−R_base；ΔC=C_base−C_patch。抑制阶段三个方向全部反转，使正数分别表示效用上升、拒答减少和 compliance 增加。1−score 不是拒答概率。

随机重复先在同 pair 内平均，再做每层、状态、干预、剂量的 pair-bootstrap（2,000 次，95% CI）、正/零/负人数。主剂量 R 与 H/random/sham 的差值在相同 pair 内计算；不把随机重复当独立样本。单一处理的二值拒答另报配对精确 McNemar 检验，随机均值不当作二值数据检验。

所有结果只作描述性探索，不生成 formal 的 F1–F4 通过判定；报告不得把未校正的描述性 p 值或正 CI 称为确认性证据。窗口用共同人口逐 pair 比较 offset 效应减中心效应。事件前的分数地板、首次不拒答的短暂性和 100 token 上限均保留为解释限制，不凭窗口差异认定机制状态依赖。

按预定网格运行，不因中间阴性效果跳过后续描述性实验，也不因个别阳性升级到 formal。仅工程、数据一致性、资源/预算异常会暂停。Subspace、正式测试、部署防御均需另立方案，不属于此次授权。

## 操作

在原 `whisper_default_v2` 环境、项目根目录执行；入口自动读取 `.env`，不输出凭据。

```bash
rq2_explore_config=configs/stage2_rq2_qwen7b_advbench_post_oracle_explore_v1_run01.json

# 仅离线来源核验及基线人口准备
python experiments/rq2_exploration.py --config "$rq2_explore_config" prepare

# 查看预计开销
python experiments/rq2_exploration.py --config "$rq2_explore_config" estimate

# 完成探索性机制、窗口和报告，不触碰 formal
python experiments/rq2_exploration.py --config "$rq2_explore_config" run \
  --from mechanism_generate --through report \
  --acknowledge-cost --accept-exploratory

python experiments/rq2_exploration.py --config "$rq2_explore_config" status
```

正常中断后可重用同一 run 命令，已完成且哈希一致的阶段会跳过。预算、回执、身份或来源异常先检查；不要改源配置或反复重新评分。
