## 操作

配置与入口：

```bash
rq2_alias_config=configs/stage2_rq2_qwen7b_advbench_v41_alias_resume01.json
```

离线准备（不加载模型、不发送API；可安全重复校验）：

```bash
python experiments/rq2_alias_resume.py --config "$rq2_alias_config" prepare
```

准备完成后，仅继续Oracle评分及报告。入口自动读取项目`.env`；如果遇到新的未知返回模型，不反复重试：

```bash
python experiments/rq2_alias_resume.py --config "$rq2_alias_config" run \
  --from oracle_judge --through report \
  --acknowledge-cost --accept-unverified-aliases
```

`validate`、`status`、`estimate` 均不调用API。不要再用旧 `rq2_replication_rejudge.py` 运行此批数据；不删除旧ledger、cache或fatal_error。
